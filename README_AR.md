# PDF Splitter — مشروع Windows

## الوظائف
- واجهة عربية وإنجليزية مع دعم RTL/LTR.
- إضافة ومعالجة عدة ملفات PDF.
- معاينة مصغرات صفحات الملف المحدد.
- تحديد الصفحات بالنقر على المصغرات ثم استخراجها في ملف مستقل.
- التقسيم حسب نطاقات الصفحات (مثل 1-3, 5, 8-10).
- التقسيم بعدد صفحات ثابت، أو صفحة لكل ملف، أو إلى عدد أجزاء.
- اختيار مجلد الإخراج وتجنب استبدال الملفات الموجودة.
- معالجة محلية على الجهاز دون رفع الملفات إلى الإنترنت.

## بناء البرنامج على Windows 10/11 (64-bit)
1. ثبّت Python 3.11 أو أحدث.
2. افتح مجلد المشروع وانقر `build_windows.bat`.
3. ينتج PyInstaller مجلد `dist\\PDF Splitter`.
4. ثبّت Inno Setup 6، وافتح `installer.iss` ثم Compile لإنشاء المثبّت داخل مجلد `installer`.

ملف EXE والمثبّت النهائيان يجب بناؤهما على Windows لضمان توافقهما.

## البناء التلقائي عبر GitHub Actions (دون تثبيت أدوات البناء محلياً)
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد، مع الحفاظ على مجلد `.github/workflows`.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build PDF Splitter for Windows** ثم **Run workflow**.
4. بعد انتهاء التشغيل بنجاح، افتح صفحة التشغيل وانزل إلى **Artifacts**.
5. حمّل `PDF-Splitter-Windows.zip`؛ ستجد داخله ملف التثبيت `PDF-Splitter-Setup.exe` ومجلد النسخة المحمولة.

يتطلب هذا المسار تشغيل GitHub Actions على Windows؛ لا يمكن إنتاج مثبت Windows أصلي من بيئة Linux الحالية مباشرة.
