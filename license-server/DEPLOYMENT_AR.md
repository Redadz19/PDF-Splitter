# تنبيه نشر — التنفيذ القديم متوقف

تعليمات النشر في هذا المجلد تخص خادم تراخيص سابقاً، ولم تعد صالحة للتنفيذ الحالي.

**لا تنشئ Render service من هذا المجلد ولا تستخدم متغيراته البيئية.**

المستودع المعتمد للنشر هو:
https://github.com/Redadz19/waraka

اتبع ملف `README.md` و`render.yaml` الموجودين في جذر مستودع WARAKA. يتضمن التنفيذ المعتمد تدفق OTP مربوطاً بالترخيص، قاعدة بيانات PostgreSQL عبر Neon، وتوقيع Ed25519.

يُحتفظ بهذا الملف لأغراض التوثيق التاريخي فقط.
