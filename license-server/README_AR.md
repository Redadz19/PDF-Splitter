# تنبيه: خادم التراخيص القديم — متوقف عن التطوير

هذا المجلد يحتوي على تنفيذ سابق لخادم تراخيص WARAKA، بواجهات API ومخطط قاعدة بيانات يختلفان عن التنفيذ المعتمد حالياً.

**لا تنشر هذا الخادم ولا تربطه بإصدار Windows الحالي.** المصدر المعتمد الوحيد لخادم التراخيص أصبح:

https://github.com/Redadz19/waraka

## الواجهات المعتمدة حالياً

- `GET /health`
- `GET /v1/public-key`
- `POST /v1/admin/licenses`
- `POST /v1/admin/licenses/{license_id}/revoke`
- `POST /v1/otp/request`
- `POST /v1/license/activate`
- `POST /v1/license/verify`
- `POST /v1/license/deactivate`

يجب مراجعة ملف README في مستودع WARAKA للحصول على تدفق التفعيل ومتغيرات البيئة الصحيحة. لا تخلط مسارات هذا الخادم القديم مع API المعتمد.

## حالة هذا المجلد

يُحتفظ بالملفات القديمة مؤقتاً للرجوع والمقارنة فقط. لم يتم حذفها لتجنب فقدان سجل التطوير، لكنها ليست جزءاً من مسار النشر الحالي.
